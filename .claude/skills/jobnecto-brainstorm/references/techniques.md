# Brainstorming techniques

Pick **3–4** per batch. Mix categories so each switch actually shifts the domain. Offer the user these ways to choose:

- **You choose** (default): pick a batch that fits the goal and announce the order.
- **Category**: the user names 1–2 categories and you draw from them.
- **Inventive**: invent 3 brand-new techniques on the spot, announce them, and log each one's name + description.

Run a technique only as long as it keeps producing. Log `[technique] started <name>` when switching.

## Structured

| Technique | How to run it | Good for |
|---|---|---|
| **SCAMPER** | Walk the topic through Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse, one letter at a time. | Improving an existing feature |
| **Five Whys** | Ask "why?" five times about the problem to reach the root cause, then ideate against the root. | Problems and bugs in the user experience |
| **Morphological Box** | List 3–4 dimensions (e.g. input, trigger, output, channel), list options per dimension, and combine one from each at random. | Feature design spaces |
| **Jobs To Be Done** | "When I ___, I want to ___, so I can ___." Generate as many jobs as possible for the target user, then ideas per job. | Product features |
| **Six Thinking Hats** | Cycle facts → feelings → risks → benefits → creativity → process, one hat per turn. | Balanced exploration |

## Deep / analytical

| Technique | How to run it | Good for |
|---|---|---|
| **First Principles** | Strip the topic to what is fundamentally true, then rebuild ideas from those truths only. | Challenging assumptions |
| **Assumption Reversal** | List 10 assumptions everyone makes about the topic and flip each into its opposite. | Breaking stuck thinking |
| **Pre-mortem** | "It is a year later and this failed badly. Why?" Turn each failure into an idea. | Risk-aware ideation |
| **Question Storming** | Generate only questions, no answers, for a fixed stretch. The best questions become prompts. | Fuzzy topics |

## Creative / lateral

| Technique | How to run it | Good for |
|---|---|---|
| **Reverse Brainstorming** | "How could we make this *worse*?" Then invert every bad idea. | Unsticking a dry session |
| **Random Word** | Pick an unrelated noun (lighthouse, sourdough, chess clock) and force connections to the topic. | Novelty |
| **Analogy Transfer** | "How would a dating app / airline / video game solve this?" Borrow their mechanics. | Fresh UX patterns |
| **Worst Possible Idea** | Deliberately terrible ideas only, then look for the kernel of value in each. | Lowering inhibition |
| **Constraint Flip** | Impose an extreme constraint: zero UI, one click, no AI, only email, 10ms latency. | Simplification |

## Speculative / future

| Technique | How to run it | Good for |
|---|---|---|
| **Time Travel** | How would this look in 1995? In 2040? Carry ideas back to today. | Vision |
| **What If Scenarios** | "What if every job seeker had a personal recruiter?" "What if vacancies applied to *you*?" | Big bets |
| **Headline From the Future** | Write the press headline for the launched product, then work backwards to features. | Positioning |

## Human / empathy

| Technique | How to run it | Good for |
|---|---|---|
| **Persona Hot-Seat** | You role-play a specific user (anxious graduate, senior engineer switching fields, recruiter) and the user interviews you. | User needs |
| **Emotion Mapping** | Walk the journey step by step (search → read vacancy → write letter → wait) and name the emotion at each step. Ideas target the lows. | UX |
| **Extreme Users** | Ideate for the edges: someone applying to 200 jobs a week, someone applying to one dream job. | Coverage |

## Wild

| Technique | How to run it | Good for |
|---|---|---|
| **Alien Anthropologist** | Describe the job-search process as an alien observer would, then question every ritual. | Radical rethinks |
| **Superpower Draft** | Give the product one superpower per round and ideate how it uses it. | Fun, novel features |
| **Mash-up** | Combine the topic with a random other product category. | Surprising combinations |

## Jobnecto seed prompts (use sparingly, to kick off)

- The moment a job seeker opens a vacancy they like: what do they need in the next 60 seconds?
- What would make a generated cover letter feel *unmistakably theirs*?
- What happens after "Apply"? Where does Jobnecto disappear from the story today?
